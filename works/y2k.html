FILE 06 / EVENT PLANNING · GROUP PROJECT

Cyber Y2K!
数据甜心工坊市集。

小组活动策划全案（31 页 PPT）：以 Y2K / 千禧年 / 赛博朋克亚文化为核心的线下市集——从主题定位、区域规划、地图布置到视觉设计与推广预算。

EVENT PLANNING / VISUAL / BUDGET六人小组 · 2025 · 全案 31 页

活动定位

01 / CONCEPT

主题「Cyber Y2K! 数据甜心工坊市集」，为小众文化爱好者与年轻消费群体策划的潮流市集：摊位区 + 美食区 + 舞台打卡 + 休憩游戏四大区域，构建集社交、休闲、娱乐、体验于一体的新消费大本营。

六大功能区

02 / ZONES

地图布置

03 / SITE MAP

场地平面按动线规划：图例覆盖舞台、打卡区、DIY 区、摊位、装置、检票处、休息区、美食区与出入口，入口气模引流、环形动线不走回头路。

视觉设计

04 / VISUAL SYSTEM

视觉系统围绕"数据甜心"展开：银色镭射质感 + 荧光撞色 + glitch 数字故障元素，从主视觉海报延展到票根、道旗，保证线上线下物料一体。

推广与预算

05 / PROMOTION & BUDGET

我的分工：场地与时间规划、节目表制作、活动文案与 PPT 制作。全案为课程小组作业，六人协作完成。
