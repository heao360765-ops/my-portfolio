FILE 05 / CHARACTER & IP DESIGN · 主推

狐念念
一只小狐狸的诞生。

原创 IP 全案：从一张 Q 版立绘出发，定义形象、表情、配色与延展规范，再落到抱枕、水杯这样的真实周边，最后做成一支会动的短片。

形象设定

01 / CHARACTER SHEETS

狐念念是一只 Q 版狐耳少女：暖橘主色配白狐尾，表情夸张但线条克制。设定阶段先把她放进不同服装与姿态里试——红裙、白裙、现代装、背面与侧身，确认"倔强、嘴硬、心软"这套性格在任何角度都站得住。

表情包矩阵

02 / EXPRESSION SET · 9 FACES

九张一套的表情，是这个 IP 最容易被记住的部分。同一张脸在圆形徽章里做减法：只靠眉眼与嘴角的变化，把"得意、委屈、炸毛、心虚、偷笑"分清楚——做周边和聊天表情都能直接取用。

配色规范

03 / COLOR SYSTEM

识别度一半来自配色。深红与正红定调，暖橘做活泼的一面，奶白留呼吸感，灰与近黑压住画面。任何延展物料里，只要这几个色在，她一眼还是念念。

DEEP RED #8F1F2A
RED #D4332F
ORANGE #D98433
AMBER #F2A83C
CREAM #F6E7D6
INK #2F2B29

周边延展

04 / MERCH & EXTENSIONS

设定不止停在画稿：抱枕与水杯两件实物打样验证了落地能力，圆形徽章则把表情包转成可以别在包上的实物——图案在不同材质、不同尺寸下都保持识别度。

动态设定

05 / MOTION · 46s

最后一步是让她动起来：一支 46 秒的短片，把立绘里的姿态拆成逐帧动作，配场景与节奏，验证这个 IP 在动态里是否还立得住。
