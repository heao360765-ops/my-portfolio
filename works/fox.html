FILE 04 / CHARACTER & IP DESIGN

狐念念
一只小狐狸的诞生。

原创 IP：从一张 Q 版立绘出发，定义性格、配色与延展规范，再落到真实周边产品。

IP CHARACTER · BRANDCSP / PROCREATE / PPT 提案

形象设定

01 / CHARACTER SHEETS

狐念念是一只 Q 版狐耳少女：暖橘主色配白狐尾，表情夸张但线条克制。设定阶段先画三视图与表情包矩阵，把"倔强、嘴硬、心软"的性格翻译成可复用的视觉符号。

配色规范

02 / COLOR SYSTEM

IP 的识别度一半来自配色。主色锁定在暖橘区间，辅以奶白与灰绿做呼吸感，强调色只留给眼睛与点缀——保证任何延展物料里她都"一眼是念念"。

PRIMARY #E8823C
CREAM #F6E7D6
GREEN #8A9A8B
INK #3A3532

周边延展

03 / MERCH & EXTENSIONS

设定不止停在画稿：抱枕与水杯两件实物延展验证了 IP 的落地能力——图案在不同材质、不同尺寸下依然保持识别度。

PLUSH抱枕 · 40cm
CUP水杯 · 500ml
