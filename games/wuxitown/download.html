BEFORE YOU SET OFF

三个步骤，开启旅程。

01 / EXTRACT

完整解压

下载完成后，右键 ZIP 选择“全部解压”。不要直接在压缩包里启动；请把 WuxiTown.exe 与 WuxiTown.pck 保留在同一文件夹。

02 / START

双击启程

双击解压后的 WuxiTown.exe，在开始界面选择角色与派系。首次进入场景需要等待加载；手机可以浏览本站，当前下载包需要 Windows 电脑运行。

03 / RETURN

随时回来

退出自动保存，下次选择继续旅程。按 Esc 调整分辨率、全屏和音量。标题设置和游戏内设置均可删除旅程存档，确认后同时清除备份并返回标题；取消不会删除。

运行环境：Windows 10 / 11（64 位），支持 Vulkan 的显卡。默认 1280 × 720，可在开始界面或 Esc 设置中调整；低配置设备优先选择 960 × 540 或 1280 × 720。当前为开发版本，尚未完成广泛硬件兼容测试。
